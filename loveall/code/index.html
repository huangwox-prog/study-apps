試合コードを入れる

選手の方はこちら。先生から聞いた8桁の数字を入れると、対戦表を見て点数を入れられます。

よくある質問

ログインはいりますか？
いりません。コードだけで入れます。

コードはどこで分かりますか？
練習試合を作った先生が知っています。先生から送られたURLを開いた場合は、コードを入れなくてもそのまま入れます。

「使えないコード」と出ます
数字がまちがっているか、先生がコードを止めた・新しくした可能性があります。先生に確かめてください。何度もまちがえると、しばらく入れなくなります。

できることは？
対戦表と点数を見ることと、自分たちの試合の点数を入れることです。組み合わせは変えられません。
