# CLEAR 引き継ぎメモ

バドミントン部の顧問向けの「リーグ戦・トーナメント作り」アプリ。
別のPCや新しい Claude Code のセッションで続きをするときは、まずこのメモを読んでから `index.html` を直す。

## どこにあるか

| もの | 場所 |
|---|---|
| アプリ本体(この1ファイルだけ) | `clear/index.html` |
| 公開ページ(GitHub Pages) | https://huangwox-prog.github.io/study-apps/clear/ (前の …/badminton-league/ を開くと自動でここへ移る) |
| claude.ai 版(持ち主だけが開ける) | https://claude.ai/artifact/6oAYFc7wQDsfhPSrSaPSWK |

- GitHub 版は保存先がブラウザ(localStorage、キー `arca-league-v1`)。端末ごとに別のデータ。
- claude.ai 版は同じ中身で、保存先が claude.ai の db(`events` コレクション、1件=1つのリーグ戦/トーナメント)。
- 2つは中身が同じ。直したら両方に反映する(claude.ai 版は Artifact の更新、GitHub 版はこのファイルを上書き)。
- 保存キーの `arca-` は旧名の名残。変えると今までのデータが読めなくなるので変えない。

## 名前とデザイン

- 名前は **CLEAR**(高く弧を描くショット「クリア」から)。**ARCA は数学アプリの名前なので使わない。**
- 見た目は数学アプリ ARCA のデザイン言語を借りている:紙(#f1f0ec)と墨の地、オーロラ(群青→菫→翠)、左下だけ大きく丸いカード、ピル型ボタン。
- ライト/ダークは上のバーのボタンで切り替え(色はすべて CSS 変数。文字のコントラストは 4.5:1 以上に合わせてある)。
- 言葉づかい:「大会」「バドミントン大会」は使わない(わかりにくいと言われた)。最初の画面は「何を作りますか？」、前に作ったものは「続きから」。キャッチコピー的な見出しは恥ずかしいので入れない。

## できること

- 形式は4つ:**練習試合** / リーグ戦 / トーナメント / リーグ戦 → 決勝トーナメント。形式で出るタブが変わる。
- **練習試合**(先生からの最初の要件。他校との合同練習・合宿用。タブは「選手 → 対戦(回転ごと) → 成績」):
  - 選手は1人ずつ(名前・学校・ランク1〜10)。ダブルスでも1人ずつ登録する(`e.practice.rounds[].matches[].a/b` が選手idの配列)。
  - 「ダブルスのペアは同じ学校どうし」(`e.practice.samePair`、初期はオン)。練習試合で学校をまたいでペアを組むことはほとんどないため。組み替えでは別の学校との組を強く避け(前と同じ相方よりも優先)、人数の都合でどうしてもできた組には「別の学校どうしのペア」と出る。固定ペアの自動作成も、オンのときは学校をまたがない。※本当に学校をまたぐことがないか、先生に確認中。
  - 「次の回転の形式」は3択:シングルス / ダブルス(ペアは毎回組み替え) / ダブルス(ペア固定)。ダブルスの2つは `e.practice.pairMode`(rotate / fixed)、ペアは `e.practice.pairs`。前は上の設定欄にも「ダブルスのペア」があって二重でわかりにくかったので、ここ1か所にまとめた。「ペア固定」を選ぶと、そのすぐ下に「固定ペア」の欄が出る。「自動でペアを作る」は同じ学校のランクが近い人どうし。名前をドラッグして別の人の上に落とすと、その2人がペアになる。ペアがいない人・相方が休みの人は待機。
  - 「第◯回転を作る」で自動の組み合わせ(関数 `genRound`)。ボタンは上の設定欄と、いちばん下の回転のあと(上と同じ形式・日・休む人で作る)の2か所。回転ごとにシングルス/ダブルスと「何日目か」を選べる。
  - 組み方:「組むときのランク差」(表示は「同じランクだけ」「前後1まで(8なら 7〜9)」「前後2まで(8なら 6〜10)」…。初期値は前後1(先生の希望。最初は「前後2〜3」と言われていたが、初期値は前後1にしてほしいと言われた))を超えないように、前の回転と同じ相手・同じ相方を避け、「なるべく別の学校の人と当てる」(初期はオン。学校が3校以上でも、マグネットで貼る代わりに使えるように)。ダブルス(組み替え)は相手1人ずつのランク差で、ダブルス(固定ペア)はペアの平均ランクの差で見る。前と同じ相手はシングルスでは強く、ダブルスでは軽めに避ける。同じ学校どうしになった試合には「同じ学校どうし:◯◯と△△」と出る(情報、黄色ではない)。できないときは一番ましな組にして、その試合に「ランク差◯(許容は◯まで)」と出す。中身は焼きなまし(入れ替えを何千回か試す)。
  - 人数が割り切れないときの待機は、それまでの試合数が多い人から。
  - 休みは2種類。「この回転だけ休み」(`round.rest`)と「今日はもう休み」(`e.practice.dayOff` = { id, day, fromId }。その日のその回転から先、新しく作る回転・組み直しで自動で外す。次の日には戻る)。置き場の名前ごとに両方のボタンがあり、「今日の休みをやめる」で戻せる。
  - 休み:作る前に「この回転は休む人」を押す(体調不良・休憩など)。作ったあとは、ドラッグで投げるだけ:名前を下の「試合に入っていない人」へドラッグすると休みになり、残りの人でその場で組み直す。置き場の名前を上の試合のほう(枠でも、試合の並んでいるところのどこでも)へドラッグすると、休みをやめてその人を必ず入れて組み直す(関数 `pDrop` / `pRegen(e, r, must)`)。「休みをやめる」ボタンも同じ。結果を1つでも入れた回転は勝手に組み直さない(枠が空くだけ/落とした枠の人と入れ替え)。ボタンは、上(元の位置)に「組み直す(シャッフル)」、休みの人がいるときだけ置き場の下に「休みの◯人を除いて、第◯回転を組み直す」。人数が余って試合がない人は「待機」と出る(何もしなくてよい)。
  - ドラッグ&ドロップ:枠どうしで入れ替え(ペア替えもこれ)、置き場へ外す、置き場から枠へ入れる。画面の上下の端に持っていくとドラッグしたままスクロールする(全ドラッグ共通)。
  - 注意とエラー:同じ人が同じ回転に2回 → エラー(赤)。空き枠 → エラー。前の回転と同じ相手/相方、ランク差オーバー、1日の上限超え → 注意(黄)。試合に入っていない人(休みにしていない人)→ 回転の上に「確認」。選手登録で同じ名前・同じ学校 → 追加させない(エラーのトースト)、既にあれば一覧に「重複」。
  - 各枠に「◯試合目」(その回転までの試合数)。選手タブにも試合数。
  - 名前は学校ごとに色分け(学校名の50音順にリーグと同じ8色。関数 `schoolColors`)。対戦画面の上に学校の色見本。選手タブ・成績タブも同じ色。
  - 成績タブ:試合数・勝敗・勝率(結果を入れた試合だけで計算)、日ごとの勝率と前の日からの増減(+25% など、ポイント差)、試合数が少ない人(最多より2以上少ない)の警告、回転ごとの出場表(● 試合 / 休 / 未)。並び順はランク順・勝率順・試合数の少ない順。
  - 成績タブは上の切り替えで2つの見かた:「試合数と勝率・出場」(上の表と出場表。先生が見やすいと言っていたので必ず残す)と「対戦結果表(紙の形)」。対戦結果表は先生が紙で使っていた対戦表と同じ並び:試合番号・回転・選手番号(選手タブの登録順、緑)・ランク・選手名/学校名・ゲーム数(勝った側を色づけ)・ゲームごとの得点・相手側の同じ列。回転ごとに絞り込めて、Excel にもコピーできる(関数 `pSheetHTML` / `pSheetBlock`)。
  - 結果は「勝ち」ボタンか点数(リーグ戦と同じ点数チェック)。Excel へは「回転ごとの対戦と結果」「成績」をコピーできる。
  - 見本:はじめの画面の「見本の練習試合を開く」(選手タブで開く)。名簿だけ(16人・架空の3校。どの学校も強い人から初心者までばらばら)。試合・結果は入れていない。実在の学校名は使わない(先生から、個人情報のようになるので避けたいと言われた)。
- シングルス / ダブルス(ダブルスは1件=1ペア。学校は1つ。違う学校同士のペアは「東高・西高」と書く)。
- 選手の入力:1人ずつ、または Excel 名簿の貼り付け。貼り付けは列を自動で見分け(番号・学年・ふりがなは使わない、「〜高校」は学校、部内順位はランクに換算)、表で見せて列ごとに選び直せる。同じ名前はとばす。
- ランクは 1〜10 の10段階(10 が強い)。数字ボタンで選ぶ。一時期 1〜5 にしたが、先生の希望で 1〜10 に戻した。保存済みの数字は換算せずそのまま使う(5段階の時期に入れた人は 1〜5 のままなので、必要なら手で直す)。Excel のランク列もそのまま 1〜10 として読む。
- 見本の選手・ペアは架空の苗字(桐生・早瀬・柏木 …)。
- 試合形式:1ゲーム / 3ゲーム(2ゲーム先取)、21点・15点・11点。
- 点数チェック:21点なら 21-19 以下、22〜29 は2点差、30-29 と 30-28 だけ正しい。勝ちが決まったあとのゲームに点があると「いらないゲームあり」。
- 棄権・不戦勝:試合ごとに「◯◯が棄権」。順位計算では「必要なゲーム数 × 点数 対 0」で数える(学校の大会でよくある扱い)。
- 勝ち負けだけの入力:選手の名前の下の「勝ち」ボタン。点数なしで 2-0(1ゲームなら 1-0)として数える。点数を入れると点数が優先。もう一度押すと取り消し。
- **1人1日6試合まで**(部の決まり。「設定を変える」の「1人1日の上限」で変更可)。リーグの人数は 3〜8人(7人で1人ちょうど6試合)。上限を超えるリーグは対戦順を「1日目/2日目」に分ける(1人ごとに数えるので、休みのある7人リーグは1日に収まる)。リーグ戦→決勝トーナメントは、合計が上限を超えると注意を出す。
- リーグ数は「1リーグの人数」にいちばん近くなるように決める(15人を7人ずつ → 8人+7人)。
- 試合と結果の画面:リーグは上に残る A B C D のボタンで選ぶ(下の「次は◯リーグ」ボタンはわかりにくいので廃止)。
- 前に作ったものは、はじめの画面の「続きから」の各カードの「削除」で消せる(確認つき)。
- 競技はひとまずバドミントンだけ。いずれ卓球・テニス・柔道・剣道など個人競技全般に広げたい(競技ごとに点数の入れ方と順位の決め方を協会の規程で確かめてから)。
- **ドラッグ&ドロップ**:トーナメント表では、選手の名前をつかんで別の枠に落とすと2人が入れ替わる。リーグ分けでは、選手をつかんで別のリーグ(または「入れない」)に落とすと移る。少し(6px)動かすまではドラッグにしないので、クリックやスクロールと区別できる。スマホの指でも動く(touch-action: none)。
- **A4 印刷**:トーナメントのタブの「印刷する」で、試合前に配る白紙の組み合わせ表(A4 縦)を印刷する。左半分(Aブロック)と右半分(Bブロック)から中央の決勝へ向かう形で、名前は枠の幅に均等割付、試合番号つき(3位決定戦は下の中央)。印刷の直前に SVG を作って `#print-area` に入れ、印刷中はそれ以外を隠す。リーグ戦の星取表の印刷はまだ(下の「次の候補」)。
- Excel への貼り付け:星取表・順位表・試合結果の一覧・トーナメントの結果。スコアは全角「－」でつなぐ(半角だと Excel で日付に化ける)。HTML の表としてもコピーする。

## 決めたルール(根拠つき)

- **リーグ内の順位**は BWF 一般競技規程(GCR)16.2 のとおり。
  1. 勝ち数
  2. 2人が並んだら直接対決の勝者が上
  3. 3人以上は 得失ゲーム差 → 得失点差(途中で2人に絞れたら直接対決)
  4. それでも並んだら同順位(画面に「抽選で決めます」と出す)
- **リーグの分け方**は2種類。
  - ランク別(A がいちばん強い組):強い順に上から区切る。部内戦・練習向き。
  - どのリーグも同じ強さ:スネーク方式(A→B→C、次は C→B→A)。強い人が各リーグに1人ずつ入る。決勝トーナメントの前向き。
  - 「1リーグの人数」(3〜6、ふつうは4)からリーグ数を決める。3人未満のリーグはできないようにしている。
  - 同じ学校はなるべく別のリーグへ(入れ替えてよい範囲だけで入れ替える)。
- **総当たりの対戦順**は円卓方式(1位候補と2位候補の対戦が最後になる。BWF の順と同じ)。
- **トーナメント**:2の累乗の枠、**シード位置は日本の組み合わせ表の形**(第1は Aブロックの一番上、第2は Bブロックの一番上、第3は Bブロックの一番下、第4は Aブロックの一番下。8枠なら A=[1,8,5,4] B=[2,7,6,3]。関数 `seedPositions`)、不戦勝は上位シードから。上半分が Aブロック、下半分が Bブロック。3位決定戦あり(切り替え可)。同じ学校が早い回戦で当たらないよう入れ替え。シードは手で指定でき、指定した選手は動かさない。決勝トーナメントは各リーグの上位(1〜4位)を A1・B1… の順にシード。

## 直し方(GitHub 版)

- このPCに git が無かったので、GitHub の画面で `index.html` を開き、中身を全部貼り替えてコミットしていた。git があるPCなら普通にクローンして直せばよい。
- 動作確認は、ローカルの簡易サーバで `index.html` を配信してブラウザで確かめていた(Excel 取り込み・順位の同率・棄権・点数チェック・スマホ幅・ライト/ダークの文字の濃さを毎回確認)。

## やっていないこと・次の候補

- リーグ戦の星取表・対戦表の印刷(トーナメントの組み合わせ表は A4 印刷に対応済み)
- 練習試合の回転ごとの対戦表の印刷、コート番号の割り当て
- 団体戦(2複3単など)
- コート割り当て・進行表(どの試合をどのコートで何番目に)
- 県・地区の大会要項ごとに順位の決め方を切り替える設定
- 日本バドミントン協会の資料ではリーグ戦の順位の条文を確認できていない(BWF の規程に合わせてある)
