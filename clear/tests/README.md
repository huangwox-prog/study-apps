# 自動テスト(画面を実際に操作して確かめる)

1. `node tests/prepare.mjs` でテスト用のページを作る(本物の Supabase にはつながない。偽物の `mock-supabase.js` を使う)
2. `cd tests` して、1つずつ動かす(Playwright と Chrome が要る。場所は環境変数 `PLAYWRIGHT` / `CHROME` で変えられる)

| ファイル | 確かめること |
|---|---|
| `run.cjs` | ログイン・まちがいの表示・新規登録・ログイン前のデータの取り込み・別の端末から読む・ログアウト・再設定 |
| `guest.cjs` | ログインせずに使う人の制限(新しく作れない・人の追加は3人まで) |
| `roster.cjs [幅]` | 部員名簿(登録・顔写真・メモ・スポーツテスト・練習試合に名簿から入れる・出場履歴)。`node roster.cjs 390` でスマホ幅 |
| `extra.cjs` | 成績の画面(日のタブ・検索・選手のページ・PDF用の出力) |
| `xss.cjs` | 名前などに仕込んだ悪いHTMLが動かないこと |

全部 `NG` が出ずに「エラーなし」で終われば合格。計算部のテストは今までどおり `src/test.html` をブラウザで開く(`PASS 86` など)。
